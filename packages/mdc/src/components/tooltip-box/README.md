# Tooltip Box (`<mdc-tooltip-box>`)

Material Design 3 `tooltip-box` component (`mdc-tooltip-box`).

## Usage

```html
<mdc-tooltip-box></mdc-tooltip-box>
```

## Properties

| Property | Type | Default |
| --- | --- | --- |
| `placement` | `TooltipBoxPlacement` | `'bottom'` |
| `offset` | `number` | `8` |
| `showDelay` | `number` | `400` |
| `hideDelay` | `number` | `0` |
| `trigger` | `TooltipBoxTriggerMode` | `'hover'` |
| `open` | `boolean` | `false` |
| `disableFlip` | `boolean` | `false` |
| `quick` | `boolean` | `false` |

## Slots

- `default`
- `tooltip`
