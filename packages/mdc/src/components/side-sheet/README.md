# Side Sheet (`<mdc-side-sheet>`)

Material Design 3 `side-sheet` component (`mdc-side-sheet`).

## Usage

```html
<mdc-side-sheet></mdc-side-sheet>
```

## Properties

| Property | Type | Default |
| --- | --- | --- |
| `variant` | `SideSheetVariant` | `'standard'` |
| `open` | `boolean` | `false` |
| `position` | `SideSheetPosition` | `'right'` |
| `handleMode` | `SideSheetHandleMode` | `'open-only'` |
| `maxWidth` | `number` | `0` |
| `quick` | `boolean` | `false` |
| `noFocusTrap` | `boolean` | `false` |
| `returnValue` | `string` | `''` |
| `showBackButton` | `boolean` | `false` |

## Slots

- `actions`
- `close-icon`
- `default`
- `headline`
- `headline-icon`
