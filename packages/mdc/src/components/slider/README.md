# Slider (`<mdc-slider>`)

Material Design 3 `slider` component (`mdc-slider`).

## Variants & Options

- **`SliderSize`**: `extra-small`, `small`, `medium`, `large`, `extra-large`
- **`SliderType`**: `standard`, `centered`, `range`

## Usage

```html
<mdc-slider></mdc-slider>
```
