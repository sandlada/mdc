# Button Group (`<mdc-button-group>`)

Material Design 3 `button-group` component (`mdc-button-group`).

## Usage

```html
<mdc-button-group></mdc-button-group>
```

## Properties

| Property | Type | Default |
| --- | --- | --- |
| `variant` | `ButtonGroupVariant` | `'connected'` |
| `selectionMode` | `ButtonGroupSelectionMode` | `'none'` |
| `selectionRequired` | `boolean` | `false` |
| `size` | `ButtonGroupSize` | `'small'` |
| `shape` | `ButtonGroupShape` | `'round'` |
| `orientation` | `ButtonGroupOrientation` | `'horizontal'` |
| `disableMorph` | `boolean` | `false` |
| `expandOnActive` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |

## Slots

- `default`
