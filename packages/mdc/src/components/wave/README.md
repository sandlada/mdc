# Wave (`<mdc-circular-wave>`, `<mdc-linear-wave>`)

Material Design 3 `wave` component (`mdc-circular-wave`, `mdc-linear-wave`).

## Usage

```html
<mdc-circular-wave></mdc-circular-wave>
```
