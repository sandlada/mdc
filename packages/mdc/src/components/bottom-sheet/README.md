# Bottom Sheet (`<mdc-bottom-sheet>`)

Material Design 3 `bottom-sheet` component (`mdc-bottom-sheet`).

## Usage

```html
<mdc-bottom-sheet></mdc-bottom-sheet>
```

## Properties

| Property | Type | Default |
| --- | --- | --- |
| `variant` | `BottomSheetVariant` | `'modal'` |
| `open` | `boolean` | `false` |
| `detent` | `BottomSheetDetent` | `'peek'` |
| `quick` | `boolean` | `false` |
| `noFocusTrap` | `boolean` | `false` |
| `returnValue` | `string` | `''` |
| `hideDragHandle` | `boolean` | `false` |
| `maxHeight` | `number` | `0` |

## Slots

- `default`
- `header`
