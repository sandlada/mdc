# Card (`<mdc-card>`)

Material Design 3 `card` component (`mdc-card`).

## Variants & Options

- **`CardVariant`**: `elevated`, `filled`, `outlined`
- **`CardShape`**: `round`, `square`

## Usage

```html
<mdc-card></mdc-card>
```

## Properties

| Property | Type | Default |
| --- | --- | --- |
| `variant` | `CardVariant` | `'filled'` |
| `interactive` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `horizontal` | `boolean` | `false` |
| `shape` | `CardShape` | `'round'` |
| `href` | `string` | `''` |
| `target` | `string` | `''` |
| `cardTabIndex` | `number` | `0` |

## Slots

- `default`
