# Tooltip (`<mdc-tooltip>`)

Material Design 3 `tooltip` component (`mdc-tooltip`).

## Usage

```html
<mdc-tooltip></mdc-tooltip>
```

## Properties

| Property | Type | Default |
| --- | --- | --- |
| `position` | `TooltipPosition` | `'top'` |
| `open` | `boolean` | `false` |
| `rich` | `boolean` | `false` |
| `plain` | `boolean` | `false` |

## Slots

- `actions`
- `default`
- `headline`
