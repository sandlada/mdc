# Checkbox

## Components

- mdc-checkbox

Use `checked` for the initial checked state and `default-checked` for the state after a form reset. To start checked and reset to checked, provide both attributes.

```html
<mdc-checkbox checked default-checked aria-label="Subscribe"></mdc-checkbox>
```
