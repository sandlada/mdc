# Popup Controller (`<mdc-popup-controller>`)

Material Design 3 `popup-controller` component (`mdc-popup-controller`).

## Usage

```html
<mdc-popup-controller></mdc-popup-controller>
```

## Properties

| Property | Type | Default |
| --- | --- | --- |
| `open` | `—` | `false` |
| `quick` | `boolean` | `false` |
| `placement` | `TPlacement` | `'bottom-start'` |
| `disableFlip` | `boolean` | `false` |
| `customAnimations` | `—` | `—` |

## Events

- `mdc-popup-closed`
- `mdc-popup-opened`

## Slots

- `surface`
- `trigger`
