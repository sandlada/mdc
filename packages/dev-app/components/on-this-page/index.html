1. Overview & Architecture

The mdc-on-this-page component delivers seamless in-page table of contents navigation conforming to Material 3 Expressive guidelines.

1.1 Purpose & Design Goals

Provides users with immediate orientation within long-form technical documentation, guides, and complex article layouts.

Maintains persistent visual hierarchy with nested subheadings while preventing layout shift during reading.

1.2 Key Features

Features include smooth scroll-spy tracking, bounding-rect matching pill indicator, inward focus ring, customizable indicator fit, and full keyboard roving accessibility.

2. Design Guidelines

Conforms to Material 3 Expressive motion tokens and typography specifications.

2.1 Layout Variants

Supports both floating sidebar positioning and embedded multi-column page layouts.

2.1.1 Standard Side Rail

Anchored to the right side of documentation pages, tracking the primary viewport scroll position.

2.1.2 Modal Drawer Integration

Used in compact screen viewports where the table of contents opens inside an overlay modal sheet.

2.2 Design Tokens

Design token mappings conforming to Material 3 Expressive standards, including container color, elevation, shape, and state layers.

2.2.1 Color Roles & Elevation

Adapts to light and dark color schemes using sys.color roles such as surface, surfaceContainer, onSurface, and primary.

2.2.2 Typography Scale

Uses Typescale.HeadlineSmall for headlines, Typescale.LabelMedium for captions, and Typescale.BodyMedium for items.

3. Interaction & Behavior

Smoothly animates indicator state transitions with spatial cubic bezier easing.

3.1 Scroll Spy Tracking

Automatically calculates threshold intersection distances to determine the currently active reading section.

3.2 Dynamic Pill Indicator

The floating pill indicator precisely aligns its bounding rectangle with the active item, supporting both content-fit and full-width modes.

3.3 State Layers & Ripple

Links provide tactile ripple feedback on click and state layer opacity transitions on hover, focus, and press.

4. Accessibility & Standards

Fully compliant with WCAG 2.2 AA accessibility requirements.

4.1 Keyboard Navigation

Supports ArrowDown, ArrowUp, Home, and End keys for rapid navigation through table of contents items.

4.2 ARIA & Screen Readers

Uses role="navigation", aria-label, aria-current="true" on the active item, and delegates focus ring outward/inward.
