Variants

Navigation rails come in primary and modal variants, accommodating both standard wide views and compact floating overlays.

When expanded, labels and destinations are displayed side-by-side or stacked vertically according to the breakpoint.

Configurations

Customize rail destinations, top app bar actions, floating action buttons (FAB), and footer items.

Destinations can include badges, tooltips, and ripple interaction feedback.

Tokens & specs

Design token mappings conforming to Material 3 Expressive standards, including container color, elevation, shape, and state layers.

Anatomy

Composed of a container, active indicator, destination icons, destination labels, and optional badges or floating action buttons.

Color

Adapts to light and dark color schemes using sys.color roles such as surface, surfaceContainer, onSurface, and primary.

States

Destinations reflect interactive states: enabled, hovered, focused, pressed, and selected with smooth transitions.

Measurements

Collapsed width defaults to 96dp; expanded width defaults to 220dp, providing ample room for descriptive labels.

Common layouts

Side-by-side layout alongside main content pane, split panes, and responsive adaptive grids for tablets and desktops.

Baseline navigation rail

Standard baseline implementation providing accessible keyboard navigation, roving tabindex, and ARIA roles.
